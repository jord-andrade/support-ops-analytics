# Security policy

## Supported version

Security fixes are applied to the latest release on `main`.

## Reporting

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability or privacy problem.

Include the affected route or module, reproduction steps, impact, and any suggested mitigation. You can expect an acknowledgement within seven days.

## Data statement

SignalDesk uses generated data only. If you believe any committed artifact contains real personal, customer, employee, credential, or proprietary data, report it privately and treat it as a security incident.
