# Contributing

Thanks for improving SignalDesk.

1. Open an issue for material product or data-contract changes.
2. Create a focused branch from `main`.
3. Run `npm ci` and `npm run check`.
4. Confirm that no fixture introduces identity, contact, free-text customer, credential, or proprietary data.
5. Open a pull request and complete the privacy and evidence checklist.

Commits should be small, imperative, and explain intent. KPI changes must update the data contract and include a hand-authored test fixture.
